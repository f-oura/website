**バージョン**: 1.0

**対象**: 研究室・機関ウェブサイト掲載用

## 1. プロジェクト概要

### 1.1 目的
ビッグバン後数マイクロ秒の宇宙初期状態を再現するインタラクティブシミュレーター。  
クォーク・グルーオン・プラズマ（QGP）フェーズから、温度低下によるハドロン自己形成までを1画面で可視化する。

### 1.2 既存システムとの関係
既存のハドロンシミュレーター（バリオン・メソン 2D可視化）の **上流フェーズ** として機能する。  
本シミュレーターのハドロン化完了状態が、既存シミュレーターの初期状態に相当する。

### 1.3 技術スタック
- HTML5 + Canvas 2D API
- Vanilla JavaScript（ライブラリなし）
- 単一HTMLファイル完結

## 2. 物理モデル仕様

### 2.1 フェーズ定義

| フェーズ | 温度範囲（無次元） | 物理的対応 | 状態 |
|---------|----------------|-----------|------|
| QGP フェーズ | T > Tc (1.0) | ~150 MeV 以上 | クォーク・グルーオン自由運動 |
| 相転移領域 | T ≈ Tc | クロスオーバー領域 | ハドロン形成開始 |
| ハドロン化フェーズ | T < Tc | ~150 MeV 以下 | ハドロン自己形成・閉じ込め |

> 閾値温度 Tc は無次元パラメーターで 1.0 に設定（スライダー範囲 0.0〜2.0）

### 2.2 登場粒子

#### クォークフレーバー（5種）

| フレーバー | 記号 | 色（RGB色荷） | 電荷 | 質量スケール | 備考 |
|-----------|------|--------------|------|------------|------|
| up | u | 赤/緑/青 いずれか | +2/3 | 軽い | 最頻出 |
| down | d | 赤/緑/青 いずれか | −1/3 | 軽い | 最頻出 |
| strange | s | 赤/緑/青 いずれか | −1/3 | 中程度 | やや稀 |
| charm | c | 赤/緑/青 いずれか | +2/3 | 重い | 稀 |
| bottom | b | 赤/緑/青 ずれか | −1/3 | 重い | 稀 |

> **色荷**：各クォークに赤(R)・緑(G)・青(B)のいずれかをランダム割当。  
> ハドロン内では RGBが揃う（バリオン）または色と反色が対（メソン）で色中性を満たす。

#### グルーオン（1種）
- 描画：波線またはスプリング形状（正弦波カーブ）
- 色：白〜グレー系（色荷8種を単純化して非着色表示）
- クォーク間を接続する線として描画

### 2.3 QGPフェーズの運動モデル

```
各クォークの加速度 = ランダム熱運動 + グルーオン交換力（T依存）
速度スケール ∝ T
グルーオン放出確率 ∝ T（高温ほど活発）
```

- クォーク同士は自由に飛び回る（閉じ込めなし）
- グルーオンはクォーク間を短時間接続し消滅（仮想粒子的表現）
- 高温では粒子の軌跡が複雑・高速

### 2.4 ハドロン化フェーズの形成モデル

#### 閉じ込めポテンシャル（線形 + クーロン型）
```
V(r) = -α/r + σ·r    （コーネルポテンシャル簡略版）

α: クーロン係数（T依存で増加）
σ: 弦張力係数（T低下で増加 → 閉じ込め強化）
```

- T < Tc で σ が急増し、クォーク間に「弦」が張る
- 弦の可視化：クォーク間を引っ張るスプリング線で表現
- 弦が伸びすぎると切断 → クォーク対生成（描画でフラッシュ演出）

#### ハドロン形成条件

| ハドロン種 | 条件 | 形成後の表示 |
|-----------|------|------------|
| バリオン（陽子/中性子） | R+G+B クォーク3体が距離d以内 | 円形バウンディングボックス + ラベル |
| メソン（π, K等） | クォーク+反クォーク（反色）が距離d以内 | 楕円形バウンディングボックス |

## 3. 描画仕様

### 3.1 全体レイアウト

```
┌─────────────────────────────────────────────────────────┐
│  [タイトル: "QGP → Hadronization"]         [宇宙年表バー] │
│                                                         │
│                                                         │
│              Canvas（メイン描画領域）                     │
│                                                         │
│                                                         │
├─────────────────────────────────────────────────────────┤
│  [🌡 Temperature: 1.85 Tc]  [ε: 2.3 GeV/fm³]  [H: 0]  │
│  [━━━━━━━━━━━━●━━━━━━━━━━]  温度スライダー               │
│  [▶ Play] [⏸ Pause] [↺ Reset]    [Speed: ●━━━]         │
└────────────────────────────────────────────────────────┘
```

- Canvas はウィンドウ全面（UIはオーバーレイ）
- UI パネルは下部半透明オーバーレイ（背景blur）
- タイトル・宇宙年表は上部オーバーレイ

### 3.2 クォーク描画

```
形状: 円（半径 6〜12px、質量に応じてスケール）
  - u, d: r=6px
  - s:    r=8px
  - c:    r=10px
  - b:    r=12px

塗り: 色荷に対応するRGB
  - 赤色荷: #FF4444
  - 緑色荷: #44FF88
  - 青色荷: #4488FF
  - 反赤:   #00BBBB（シアン）
  - 反緑:   #BB00BB（マゼンタ）
  - 反青:   #BBBB00（イエロー）

ラベル: 中央に "u" "d" "s" "c" "b" をフォント表示
グロー: 色荷と同色の外縁ぼかし（shadowBlur = 8）
```

### 3.3 グルーオン描画

```
形状: 2点間を結ぶ正弦波カーブ
  振幅: 4px
  波長: 12px
  色:   白 (#EEEEEE) 透明度 0.6
  太さ: 1.5px

寿命: 5〜15フレーム（出現→フェードアウト）
```

### 3.4 弦（コンファインメント）描画

```
形状: クォーク間を結ぶ直線 + 振動アニメーション
  色:     温度に応じてグラデーション
          高温: 薄いオレンジ
          低温: 太い白線（閉じ込め強）
  太さ: 1 + (1-T/Tc) * 4 px
  張力可視化: 弦が長いほど赤み増加
```

### 3.5 ハドロン形成エフェクト

```
形成瞬間:
  - 閃光（白フラッシュ、半径30px、10フレームでフェード）
  - バウンディングサークルがパルスアニメーション（拡大→収縮）

形成後:
  - 半透明円 or 楕円でグループを囲む
  - 右下にラベル表示（"p", "n", "π+", "K0" 等）
```

### 3.6 背景・雰囲気演出

```
背景: 完全な黒 (#000000)
星フィールド: 微小な白点（静的、z-index最背面）
温度グラデーション: 画面全体に薄いオーバーレイ
  高温: 微かな赤みがかったグロー
  低温: 通常の黒背景
フェーズ境界: T≈Tc 付近でさざ波エェクト（Canvas全体を短く振動）
```

## 4. UI・操作仕様

### 4.1 温度スライダー

```
範囲: 0.0 〜 2.0 (Tc単位)
初期値: 2.0（完全QGPフェーズ）
ステップ: 0.01
表示: "T = 1.85 Tc" または "T = 185 MeV"（切替ボタンで単位変更）

挙動:
  スライダーを動かすと即時に物理パラメーターが更新される
  T > 1.0: QGPフェーズ（閉じ込めなし）
  T ≈ 1.0: 相転移領域（部分的ハドロン形成）
  T < 1.0: ハドロン化フェーズ（閉じ込め有効）
```

### 4.2 スクロール制御

```
スクロールダウン: シミュレーション時間を進める（温度は固定）
スクロールアップ: 時間を巻き戻す
スクロール速度: 時間進行速度に対応
```

### 4.3 再生・停止・リセット

```
▶ Play:  アニメーション開始（温度を 2.0→0.2 に自動低下）
⏸ Pause: アニメーション一時停止
↺ Reset: 粒子を初期配置に戻す（T=2.0）
Speed:   自動低下速度スライダー（遅い〜速い）
```

### 4.4 クォーククリック

```
クォークをクリックすると情報パネルが表示される:
  ┌──────────────────┐
  │ 🔴 up quark (u)   │
  │ 電荷: +2/3        │
  │ 色荷: Red         │
  │ 速度: 0.73c       │
  │ 運動量: ...       │
  └──────────────────┘

パネルはクォーク近傍にツールチップとして出現
他の場所をクリックで閉じる
```

### 4.5 情報オーバーレイ（常時表示）

```
左上:
  T = [値] Tc  /  [値] MeV
  ε = [エネルギー密度] GeV/fm³
  ハドロン数: [整数]
  自由クォーク数: [整数]

右上:
  宇宙年表バー（横線）
  ビッグバン ──●── 現在地 ────── 陽子形成完了
               ↑
           t ≈ 1μs
```

## 6. フレーバー別生成比率とハドロン種

### 6.1 クォーク生成比率（初期）

```
u quark:   40%  → 24個
d quark:   40%  → 24個
s quark:   15%  →  9個
c quark:    4%  →  2個

（合計 60個）
```

## 7. アニメーションループ仕様

```javascript
// 毎フレーム処理順序（60fps目標）
1. 温度パラメーターの更新（自動モード時）
2. 背景クリア + 星フィールド描画
3. 温度オーバーレイ描画
4. グルーオン更新・描画（寿命管理）
5. 弦（ポテンシャル）計算・描画
6. クォーク運動更新（熱速度 + ポテンシャル力）
7. ハドロン形成チェック（距離 + 色中性条件）
8. ハドロン・自由クォーク描画
9. 形成エフェクト描画（フラッシュ等）
10. UIオーバーレイ描画（情報・宇宙年表）
```

## 8. 既存シミュレーターとの接続方針

| 項目 | 本シミュレーター | 既存ハドロンシミュレーター |

| 対象フェーズ | QGP → ハドロン化 | ハドロン核物理 |
