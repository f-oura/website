# Claude Code プロンプト — website2026 リデザイン

## 目的
Hugo + Congo テーマで構築された研究者個人サイト `website2026` のトップページを、
**monopo.co.jp スタイル**（大胆なタイポグラフィ × エディトリアルな黒基調）に改善する。

変更対象は **2ファイル + 1ファイル新規作成** のみ。Congoテーマ本体は一切触らない。

---

## 参照サイトのデザイン特徴（monopo.co.jp）
- **黒背景**に白テキスト
- ナビは小文字・細字・横並び、シンプルで余白たっぷり
- ヒーローは**全画面**。大文字の英字キャッチコピーが画面いっぱいに広がる
- タイポグラフィ主役：フォントサイズの差で視覚的ヒエラルキーを作る
- 余白（ネガティブスペース）を積極的に使う
- フォント：セリフなし、コンデンス系または通常ウェイト混在
- アニメーション：控えめ（フェードイン、ゆっくりスクロール演出程度）

## 実施する変更

### 変更1: `config/_default/params.toml`
以下の2行を変更する：
```toml
# 変更前
defaultAppearance = "light"
# 変更後
defaultAppearance = "dark"
```

### 変更2: `assets/css/schemes/laboratory.css` を全書き換え
黒背景ベースのダークスキームに変更する。
`--color-neutral-900` が最も暗い色（ほぼ黒 `#0a0a0a`）、`--color-neutral` が白になるよう設計。

以下を参考に、モノポスタイルの黒基調カラースキームを実装：
```css
:root {
  --color-neutral: 255, 255, 255;
  --color-neutral-50: 250, 250, 250;
  --color-neutral-100: 240, 240, 240;
  --color-neutral-200: 210, 210, 210;
  --color-neutral-300: 170, 170, 170;
  --color-neutral-400: 130, 130, 130;
  --color-neutral-500: 100, 100, 100;
  --color-neutral-600: 70, 70, 70;
  --color-neutral-700: 45, 45, 45;
  --color-neutral-800: 25, 25, 25;
  --color-neutral-900: 12, 12, 12;
  --color-neutral-950: 5, 5, 5;
  /* primary = 白系アクセント */
  --color-primary-50: 255, 255, 255;
  /* ... 白からグレーのグラデーション */
  --color-primary-900: 30, 30, 30;
  --color-primary-950: 10, 10, 10;
}
```

### 変更3: `assets/css/custom.css` を全書き換え（メイン作業）
モノポスタイルの以下の特徴をすべて実装する：

#### 3-1. ベース
- `body` 背景色: `#0a0a0a`（ほぼ黒）
- テキスト色: `#f0f0f0`（ほぼ白）
- フォントファミリー: Google Fonts から `'Syne'`（見出し用・コンデンス感あり）+ `'Inter'`（本文用）をインポート。ただしCSSの `@import` ではなく、`layouts/baseof.html` の `<head>` 内に `<link>` タグを追加すること

#### 3-2. ヒーロー（トップページ）
`homepage layout = "profile"` のCongoデフォルトを上書きして、以下のスタイルにする：

- プロフィール画像は**非表示**（`display: none`）
- 著者名 `h1` を **`clamp(3.5rem, 8vw, 9rem)`** の巨大サイズに
- 著者名のフォント: `'Syne'`, `font-weight: 700`, `letter-spacing: -0.02em`, `line-height: 0.9`
- キャッチコピー（`# Exploring Particles...` の h1）も大きく、`font-weight: 300`
- テキストは**左揃え**（Congoのデフォルト中央揃えを上書き）
- ヒーローエリア全体の `min-height: 85vh`、縦中央揃え（`display: flex; flex-direction: column; justify-content: flex-end; padding-bottom: 4rem`）← 画面下部にテキストを配置するモノポスタイル

#### 3-3. ナビゲーション（ヘッダー）
- フォント: 小文字、`font-size: 0.75rem`, `letter-spacing: 0.15em`, `font-weight: 400`
- 背景: 透明
- ボーダー: なし
- ホバー: アンダーラインがスライドイン（`::after` 擬似要素でwidth 0→100%アニメ）
- サイトタイトル: `font-weight: 300`, `text-transform: uppercase`, `letter-spacing: 0.2em`

#### 3-4. 粒子SVGアニメーション（`baseof.html` 内の `.particle-graphic`）
- 現行の `opacity: 0.5` → `opacity: 0.08`（ほぼ見えなくする）
- または完全に削除しても可
- ダーク背景に白い粒子線は主張しすぎるため、背景の邪魔にならないよう調整

#### 3-5. フェードインアニメーション
ページロード時に以下をフェードイン：
```css
@keyframes fadeUp {
  from { opacity: 0; transform: translateY(20px); }
  to   { opacity: 1; transform: translateY(0); }
}
/* 見出し、本文、ナビに animation-delay を段階的に適用 */
```

#### 3-6. タイポグラフィ全体
- `h1`: `clamp(3rem, 7vw, 8rem)`, Syne, weight 700, letter-spacing -0.02em
- `h2`: `clamp(1.5rem, 3vw, 3rem)`, Syne, weight 400
- `h3`, `h4`: Syne, weight 400, uppercase
- 本文: Inter, 1rem, line-height 1.7, color `#b0b0b0`
- リンク: 下線なし、ホバーで `color: #ffffff`

#### 3-7. カード・リスト
- `background: rgba(255,255,255,0.03)`
- `border: 1px solid rgba(255,255,255,0.08)`
- `border-radius: 0`（角丸なし）
- ホバーで `background: rgba(255,255,255,0.07)` に変化

#### 3-8. フッター
- `border-top: 1px solid rgba(255,255,255,0.1)`
- テキスト: `#555`, フォントサイズ `0.7rem`, uppercase, letter-spacing
